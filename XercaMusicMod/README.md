# Music Maker Mod

This is a Minecraft mod that adds the ability to create and play music to the game. For details, please visit the mod
page: http://ercanserteli.com/music-maker-mod/

## Sky mode (fork addition)

This fork adds a "Sky: Children of the Light"-style playing interface. Toggle it with the **Sky Mode** button at the
top right of the instrument screen.

- 15 note buttons (Y U I O P / H J K L ; / N M , . /) covering two octaves plus the top tonic
- 6 chord buttons (R T / F G / V B) for the I–vi triads, played two octaves below the note area
- `[` `]` or `A` `S` change the octave
- The chosen mode is remembered while the game is running
